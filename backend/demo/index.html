Backend Engineer (Python)

Nimbus Pay · Lahore, Pakistan · Full-time · Hybrid

Apply for this job

About the role

Nimbus Pay is building fast, reliable payments for small businesses across South Asia. We're hiring a Backend Engineer to design and run the APIs behind our checkout and payouts products.

What you'll do

  • Design, build and maintain REST APIs in Python (FastAPI).
  • Model data in PostgreSQL and keep it fast and correct.
  • Ship features end to end with product and mobile teams.
  • Improve reliability, monitoring and on-call runbooks.

What we're looking for

  • 3+ years of professional backend development.
  • Strong Python; experience with FastAPI or Django.
  • SQL and PostgreSQL in production.
  • Docker and CI/CD; cloud experience is a plus.
  • Clear written communication.

Nice to have

  • Payments or fintech experience.
  • Kubernetes.
